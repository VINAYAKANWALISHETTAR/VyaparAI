Tech stack

The tools and libraries that make VyaparAI reliable, fast, and easy to audit — including an in-house LLM deployed on Render.

FlutterCross-platform Android app with Riverpod state management, GoRouter navigation, Dio for HTTP, speech_to_text for voice, flutter_tts for audio, and flutter_local_notifications for alerts.
FastAPIHigh-performance Python REST API with Pydantic validation, JWT authentication, bcrypt password hashing, CORS, Swagger docs, and WebSocket support for real-time features.
PyTesseract + RapidOCRDual OCR pipeline for invoice and payment screenshot reading. PyTesseract with Pillow preprocessing and RapidOCR via ONNX Runtime for cloud-free, on-device inference. No external OCR API dependency.
MongoDB AtlasMulti-tenant document database with indexed queries for users, businesses, invoices, transactions, reminders, and notifications.
In-house LLM / ML modelOur own custom-trained NLP model powers intent classification, natural-language understanding, and answer phrasing. Trained in-house and deployed on Render for low-latency inference. It sits alongside deterministic rule-based checks for finance.
Rule-based intelligencePayment matching, anomaly detection, receivable aging, cash-flow forecast, and insights are deterministic. The LLM classifies intent and explains results; it never computes money.

Deployment: Backend and the in-house LLM are deployed on Render. The Flutter app is distributed as an Android APK. MongoDB Atlas hosts the multi-tenant cloud data layer.

The records exist. The picture doesn't.

A business owner's financial reality is spread across six disconnected systems. Each one is accurate in isolation. None of them adds up the others. The critical question — "What is my financial position right now, and what should I do next?" — has no single answer.

  • UPI paymentsReceived money sits in payment-app screenshots, unmatched to any bill.
  • Bank messagesCredits and debits arrive as SMS, one at a time, with no context.
  • InvoicesPaper or photos, with due dates nobody is watching.
  • ReceiptsExpenses in a drawer or a camera roll, never summarized.
  • WhatsAppSupplier bills and "I'll pay Friday" buried in chat threads.
  • Bahi-khataThe handwritten book, kept up to date only by you.

      How the numbers are made, and where VyaparAI is today

      • Plain arithmetic for money. Income, expenses, profit, receivables, liabilities and forecasts are calculated by Python code. Nothing is estimated by a language model. The LLM only works out which question you asked and phrases the verified result.
      • You confirm what was read. Invoices and payments read from images are saved only after you confirm them. The backend checks for duplicate payments by reference before storing anything.
      • "Recorded" means recorded. VyaparAI shows a recorded cash position from what you have captured. It does not connect to your bank, so it never claims to show a bank balance.
      • Flags, not accusations. Unusual items are marked "appears unusual, please review". Anomaly detection uses three rule-based checks: duplicate invoice numbers, payment above invoice amount, and expense over 3× category average.
      • Your data stays separate. Sign-in uses JWT tokens, passwords are hashed with bcrypt, and every query is limited to your own business. Data is stored in MongoDB Atlas with proper indexes.

      Questions, answered plainly

      What is VyaparAI?

      VyaparAI is an AI-powered financial copilot for small Indian businesses. It reads invoices and payment screenshots using OCR, matches payments to bills, tracks receivables and liabilities, forecasts cash flow, flags unusual transactions, and answers money questions by text or voice. It is built for merchants, freelancers and informal shop owners who keep records across UPI, invoices, WhatsApp and handwritten bahi-khata.

      Who is it for?

      Small merchants, freelancers and informal business owners in India who already have financial information spread across UPI screenshots, bank SMS, invoices, receipts, WhatsApp messages and handwritten records — but not the time or accounting background to consolidate them.

      Which phones does it run on?

      The download on this page is an Android APK. The minimum Android version is shown in the download section once the APK is published.

      How do I install an APK?

      Download it, open the file, allow the install if Android asks, then tap Install. The full steps are in the download section above.

      Does an AI model calculate my money?

      No. Totals, balances, forecasts and all financial figures are calculated by deterministic Python code in the financial engine. The assistant only works out which question you asked and phrases the verified result in natural language. This is a core architectural guarantee: the LLM never becomes the source of truth for money.

      Which languages does voice support?

      The voice backend detects English, Hindi and Kannada. In the mobile app, speech recognition processes native audio queries and passes intents directly into the copilot, returning verified financial results in your chosen language.

      Does it show my bank balance?

      No. VyaparAI does not connect to bank accounts. It shows a recorded cash position based on the payments, transactions and invoices you have captured. What you have not recorded is not shown.

      Can I generate and download reports?

      Yes. VyaparAI provides comprehensive daily, weekly, monthly, and yearly financial reports. You can view interactive category breakdowns, income vs. expense analytics, and download official, beautifully formatted PDF statements generated by the backend ReportLab PDF engine or export CSV files.

      How is my data handled?

      Sign-in uses JWT tokens and passwords are hashed with bcrypt. Each business's data is kept separate in MongoDB Atlas, and every query is limited to the signed-in owner's business. The backend enforces business ownership verification on all sensitive operations.

      What is the tech stack?

      Mobile app: Flutter with Riverpod state management, GoRouter and Dio. Backend: FastAPI with Pydantic validation, MongoDB Atlas, PyTesseract OCR, ReportLab PDF engine, and JWT authentication. AI & Intelligence: Google Gemini AI Copilot for natural language understanding and deterministic Python financial engine for 100% error-free accounting math. Languages: English, Kannada, Hindi with 100% UI parity.
